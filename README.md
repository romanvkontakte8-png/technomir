## Установка и запуск

```bash
# 1. Установить зависимости
npm install

# 2. Создать и наполнить базу данных
npm run init-db

# 3. Запустить сервер
npm start
```

Сервер запустится на **http://localhost:3000**

## Функциональность

### Каталог товаров
- Просмотр всех товаров с фильтрацией по категориям
- Поиск товаров по названию, бренду и описанию
- Карточки товаров с ценами и изображениями

### Страница товара
- Подробная информация о товаре
- Полная таблица характеристик по группам
- Добавление товара в список сравнения

### Система сравнения товаров
- Добавление до 6 товаров к сравнению
- Таблица сравнения всех характеристик
- Подсветка различающихся характеристик (жёлтым)
- Фильтр «Только различия» — скрывает одинаковые строки
- Удаление товаров из сравнения
- Хранение списка сравнения в localStorage

### API (REST)
- `GET /api/categories` — список категорий
- `GET /api/products?category_id=&search=` — список товаров
- `GET /api/products/:id` — товар с характеристиками
- `POST /api/compare` — сравнение товаров по массиву `ids`

## База данных (SQLite)

### Таблицы
- **categories** — категории товаров (id, name, slug)
- **products** — товары (id, name, slug, category_id, price, old_price, image, description, brand, in_stock)
- **product_specs** — характеристики (id, product_id, spec_group, spec_name, spec_value)

### Наполнение
БД содержит 20 товаров электроники:
- Смартфоны (Apple iPhone, Samsung Galaxy, Xiaomi)
- Ноутбуки (MacBook Pro, ASUS ROG, Lenovo ThinkPad)
- Планшеты (iPad Pro, Galaxy Tab)
- Наушники (AirPods Pro, Sony WH-1000XM5, Galaxy Buds)
- Умные часы (Apple Watch Ultra, Galaxy Watch)
- Телевизоры (Samsung QD-OLED, LG OLED)
