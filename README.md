## Быстрый запуск

### Требования
- **Node.js** (версия 18+) — скачать: https://nodejs.org/

### Windows
Дважды кликните по файлу **`start.bat`** — сайт откроется автоматически.

### macOS / Linux
```bash
chmod +x start.sh
./start.sh
```

### Ручной запуск (любая ОС)
```bash
npm install
npm run init-db
npm start
```

Сервер запустится на **http://localhost:3000**

### Тестовые аккаунты
| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` | `password` |
| Клиент | `user` | `password` |

### Без сервера (офлайн-каталог)
Откройте файл `public/index.html` в браузере — каталог, страницы товаров и сравнение работают без сервера.

## Функциональность

### Каталог товаров
- Просмотр всех товаров с фильтрацией по 7 категориям
- Поиск товаров по названию, бренду и описанию
- Карточки товаров с ценами, изображениями и кнопкой сравнения

### Страница товара
- Подробная информация о товаре
- Полная таблица характеристик по группам
- Добавление товара в корзину и сравнение

### Система сравнения товаров
- Добавление до 6 товаров к сравнению
- Таблица сравнения всех характеристик
- Цветовая индикация: зелёный = лучше, красный = хуже
- Итоговая оценка и бейдж «Лучший выбор»
- Фильтр «Только различия»
- Кнопка «В корзину» для каждого товара

### Авторизация и роли
- Регистрация и вход (2 роли: клиент и администратор)
- JWT-токены (SHA-256, срок 7 дней)

### Корзина и заказы
- Добавление товаров в корзину, изменение количества
- Оформление заказа с адресом доставки
- Система баланса: пополнение, проверка при оплате, возврат при отмене
- История заказов в личном кабинете

### Админ-панель
- Список всех пользователей
- Редактирование профилей пользователей (имя, логин, роль, баланс)
- Все заказы с фильтрацией по статусу
- Управление статусами заказов

### Дополнительно
- Тёмная/светлая тема (переключатель в шапке)
- Редактирование профиля
- Адаптивный дизайн
- Работа без сервера (офлайн-каталог через file://)

## API (REST)

| Метод | Маршрут | Описание |
|-------|---------|----------|
| GET | `/api/categories` | Список категорий |
| GET | `/api/products?category_id=&search=` | Список товаров |
| GET | `/api/products/:id` | Товар с характеристиками |
| POST | `/api/compare` | Сравнение товаров `{ids: [1,2,3]}` |
| POST | `/api/auth/register` | Регистрация |
| POST | `/api/auth/login` | Вход |
| GET | `/api/auth/me` | Текущий пользователь |
| PUT | `/api/auth/me` | Обновление профиля |
| POST | `/api/auth/topup` | Пополнение баланса |
| GET | `/api/orders` | Заказы пользователя |
| POST | `/api/orders` | Создать заказ |
| PUT | `/api/orders/:id/cancel` | Отменить заказ |
| GET | `/api/admin/users` | Все пользователи (админ) |
| PUT | `/api/admin/users/:id` | Обновить пользователя (админ) |
| GET | `/api/admin/orders` | Все заказы (админ) |
| PUT | `/api/admin/orders/:id/status` | Сменить статус заказа (админ) |

## База данных (SQLite)

### Таблицы
- **categories** — категории товаров (id, name, slug)
- **products** — товары (id, name, slug, category_id, price, old_price, image, description, brand, in_stock)
- **product_specs** — характеристики (id, product_id, spec_group, spec_name, spec_value)
- **users** — пользователи (id, name, email, phone, password, role, balance, created_at)
- **orders** — заказы (id, user_id, status, total, address, comment, created_at)
- **order_items** — товары в заказах (id, order_id, product_id, quantity, price)

### Наполнение
БД содержит 18 товаров электроники:
- Смартфоны (Apple iPhone, Samsung Galaxy, Xiaomi)
- Ноутбуки (MacBook Pro, ASUS ROG, Lenovo ThinkPad)
- Планшеты (iPad Pro, Galaxy Tab)
- Наушники (AirPods Pro, Sony WH-1000XM5, Galaxy Buds)
- Умные часы (Apple Watch Ultra, Galaxy Watch)
- Телевизоры (Samsung QD-OLED, LG OLED)
