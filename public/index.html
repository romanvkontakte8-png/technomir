Наша система сравнения товаров помогает клиентам быстро и наглядно оценить характеристики и выбрать оптимальное устройство по соотношению цена-качество.

Дипломный проект

Разработка интернет-магазина электроники «ТехноМир»

Информация о проекте

Тема: Разработка веб-приложения интернет-магазина электроники «ТехноМир»

Автор: Григорьев Ярослав Максимович

Группа: СИП 433/22

Учебное заведение: Колледж информатики и программирования

Год: 2026

Проект представляет собой полнофункциональный интернет-магазин с каталогом товаров, системой сравнения, личным кабинетом, корзиной, оформлением заказов и административной панелью управления.

Функциональные возможности

  • ✓ Каталог товаров с фильтрацией по категориям и поиском
  • ✓ Система сравнения характеристик товаров
  • ✓ Регистрация и авторизация по электронной почте
  • ✓ Личный кабинет с редактированием профиля
  • ✓ Корзина и оформление заказов
  • ✓ Система пополнения баланса и оплаты
  • ✓ Админ-панель для управления пользователями и заказами
  • ✓ Переключение тёмной и светлой темы
  • ✓ Адаптивный дизайн для мобильных устройств

Стек технологий

Технологии, использованные при разработке проекта

Frontend
HTML5, CSS3 (адаптивный дизайн, тёмная/светлая тема, glassmorphism), JavaScript ES6+ (модули, async/await, Fetch API)
Backend
Node.js — серверная среда выполнения, Express.js — веб-фреймворк, REST API (16 эндпоинтов)
База данных
SQLite — файловая реляционная СУБД, better-sqlite3 — драйвер для Node.js, 6 таблиц
Безопасность
SHA-256 хэширование паролей, Bearer-токен авторизация, валидация данных на сервере
